# Ponytail vendoring

This directory vendors the `ponytail` coding skill from
`DietrichGebert/ponytail`.

- Upstream commit: `e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156`
- Upstream release at that commit: v4.10.0
- Vendored file: `skills/ponytail/SKILL.md`
- Licence: MIT; see `LICENSE`

`SKILL.md` is intentionally kept verbatim from upstream. Repository-specific
precedence and architectural constraints live in the root `AGENTS.md` and
override the generic Ponytail guidance when a shorter implementation would
weaken a settled `pj` contract.

Default repository use is Ponytail **full** mode. Do not use **ultra** unless
the operator explicitly requests it.
